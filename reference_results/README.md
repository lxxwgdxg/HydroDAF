# Reference Public Benchmark Results

These files are the public CAMELS-US results used in the revised manuscript:

- `public_camels_main_recommended_metrics_raw.csv`: raw target-seed-model metrics.
- `public_camels_main_recommended_metrics_summary.csv`: station-level mean and standard deviation.
- `Table_public_CAMELS_main_recommended_average_formatted.csv`: model-wise public benchmark table reported in the main text.
- `Table_public_CAMELS_main_recommended_formatted.csv`: station-level public benchmark table for supplementary material.
- `Table_public_CAMELS_station_selection_main_recommended.csv`: selected station descriptors.
- `Table_public_CAMELS_sensitivity_02361000_formatted.csv`: supplementary sensitivity station.

The local proprietary benchmark results are intentionally not included in this public repository package.
